# Airlock — visual language

Portfolio surface for Fischer Product Lab. This is a cinematic, read-only demonstration — not a night SaaS, not a title-card overlay on the range board.

## Tokens

| Token | Hex | Role |
| --- | --- | --- |
| Navy | `#0B1220` | Void. Page, canvas, chrome. |
| Ivory | `#F4EFE4` | Type, Conditional, and the primary CTA fill. |
| Gold | `#C4A35A` | Sealed. The only accent. Rules, meta, rim-light, secondary CTA. |

Atmosphere is one thing: **film grain + a single gold/ivory light** sitting over a real Airlock product window. Status color is meaning, not decoration. Gold is Sealed. Ivory is Conditional. A single red is a leak or a stop, and it is used sparingly.

## Type

Landing face: **Geist**. Mono: **Geist Mono**. Loaded via `next/font`. The live demo screens keep Hanken Grotesk + Fraunces so the product chrome stays itself.

Four sizes on `/`, no more:

| Name | Use |
| --- | --- |
| Display | Hero headline only |
| Title | Section heads |
| Body | Subcopy and how-it-works |
| Meta | Eyebrows, nav, footer — mono, tracked, uppercase |

## Kill list

- No purple. No indigo mesh. No default shadcn violet.
- No Inter as the face.
- No emoji icons.
- No Spline / R3F orb.
- No fake “trusted by” logos.
- No five CTAs. Two: **Open the demo** and **See how it decides**.
- No auth, Stripe, CMS, or a second product.
- No invented metrics.
- No exploit, payload, or attack procedure.
- Do not copy TrustDesk copy or chrome. Steal the register: void, one light, grain, grotesque headline, real product under the light.
